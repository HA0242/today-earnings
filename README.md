# 今天挣了多少钱 (Today's Earnings)

一个极简的 macOS 原生应用，按你设置的月薪和上班时间段，实时算出"现在这一秒你挣了多少钱"，并支持按自然月记账（工作日历、请假、加班）。

用 SwiftUI 写成，没有任何第三方依赖，界面跟随系统浅色/深色外观自动切换。

## 功能

### 首页：实时收入
- 大字显示今天已经挣到的钱，按"每秒 / 每分钟 / 整点"三种频率自动跳动
- 今日进度条：当前处于"还没上班 / 正在上班 / 休息中 / 已下班"哪个阶段，以及距离下一个状态还有多久
- 日薪、时薪、每秒收入三个速率参考
- 本月已挣（自然月累计，实时计算）

### 日历：工作日历 + 请假/加班记账
- 按月勾选哪些天算工作日（默认周一至周五，可自定义，且会沿用上个月的排班作为默认值）
- 给任意一天记"请假"（可选是否扣薪）或"加班"（可选是否加钱、加班时长），互不冲突
- 月度汇总卡：本月已挣、预计全月、请假扣款、加班费一目了然

### 统计：月度报告
- 自然月累计收入、预计全月收入、工作日/请假/加班三项摘要
- 当月请假/加班记录明细列表，每条记录对当月收入的净影响（+加班费 / -扣薪）

### 设置
- 月薪、多段上班时间段（支持跨零点的夜班时间段）、刷新频率（每秒/每分/整点）
- **多角色记账**：可以同时管理多份独立的记账数据（比如"主账户"+ 兼职角色 A、角色 B……），每个角色有各自独立的月薪、时间段、日历和请假/加班记录，互不影响。角色之间随时切换、可新增/改名/删除（主账户不可删除，保证至少留一份数据）

## 系统要求

macOS 14.0 及以上。

## 下载

打包好的 `.dmg` 在 [Releases](https://github.com/HA0242/today-earnings/releases) 里，下载安装即可，无需 Xcode。

## 从源码构建

需要一台装了 Xcode 命令行工具的 Mac（不能在远程/容器环境里跑，因为要用 `sips`/`iconutil`/`hdiutil` 这些系统工具）：

```bash
git clone https://github.com/HA0242/today-earnings.git
cd today-earnings
bash build/build_app.sh
```

跑完之后会在项目根目录生成 `今天挣了多少钱.app` 和 `今天挣了多少钱.dmg`。

## 项目结构

```
src/                核心 Swift 源码
  Shared.swift        数据模型、收入计算、多角色存储
  TodayEarningsApp.swift  App 入口、主页面、设置页
  CalendarPage.swift  日历/记账页
  StatsPage.swift     月度统计页
assets/             App 图标原始素材
build/              打包脚本（编译、生成图标、打 dmg）
```

## 数据存储

所有数据都存在本机 `UserDefaults`（suite: `local.ha.today-earnings.shared`），不联网、不上传，完全离线。
